# Design schema contract

Current design AST version is schema 1.0 at `schema/design-spec-1.0.schema.json`, typed in `src/shared/spec.ts`. Supported types: frame, group, text, rectangle, ellipse and line. Container children recurse with 16-depth and 2,000-node limits; full JSON is limited to 512 KB. IDs are unique across the document.

Schema 1.0 supports native frames/groups/components/instances, bounded SVG paths, embedded PNG/JPEG bytes (256 KiB each), linear gradients, bounded solid/linear-gradient paint stacks (up to eight), drop shadows, named color/text tokens, responsive constraints, and row/column/grid layout grids. Rendering converts tokens into local Figma Variables and Text Styles. Selected-tree export preserves supported appearance and token references; it reports unsupported cases (such as image paints stacked with other paints, non-drop-shadow effects, unresolved modes, or missing component sources) instead of silently dropping them. Any future incompatible change needs an explicit schema version and migration.
