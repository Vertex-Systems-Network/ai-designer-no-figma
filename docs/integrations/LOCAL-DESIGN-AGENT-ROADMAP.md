# Local design agent: lessons from Figma's MCP guide

Reviewed 2026-11-12 against [figma/mcp-server-guide](https://github.com/figma/mcp-server-guide), especially its `figma-generate-design`, `figma-generate-library`, `figma-use`, and validation/recovery references. This is a workflow and Plugin API capability study. The official repository is a configuration/skills package for Figma's hosted service, not source code for a self-hosted Figma server. Its `use_figma` execution endpoint, `get_libraries`, `search_design_system`, `generate_image`, `html_to_figma` and cross-file access are service features. Copying its MCP JSON does not provide those abilities locally.

Phase 2 validates a versioned plan and its embedded native design; inventory still lacks resolved token values, so the plan must declare them in schema 1.0. | Host mock plus live file showing actual discovered assets |

## Agent contract for current version

1. Compose schema 1.0 JSON from a brief and available user-managed tokens. Use specific copy, semantic names and supported native properties; plan image slots only when real asset bytes are available.
2. Call `figma_audit_design_schema` locally. Fix schema errors before import; review warnings. Geometry checks are advisory because Figma font metrics and Auto Layout positions require rendering.
3. Call `figma_import_design_schema`, poll `figma_get_job_result`, then `figma_capture_selection` on the created frame. Inspect the returned JPEG. Do not call it visually verified without seeing the actual image.
4. If needed, inspect selection and apply a small explicit patch to current selected IDs, then capture again. Stop when the requested composition has been checked; report any unfixable mismatch.

This works with our custom local MCP bridge, no Figma hosted MCP token or Figma REST token. The bridge still requires its **local pairing credential** to prevent arbitrary processes from mutating the open document; “no MCP token” means no Figma-hosted token, not unauthenticated local write access. A capable AI model/client is still needed to interpret a brief or image. The default copy/paste path needs no inference API, while optional Ollama needs an installed local model. We cannot establish visual parity with Figma Agent from protocol tests.
