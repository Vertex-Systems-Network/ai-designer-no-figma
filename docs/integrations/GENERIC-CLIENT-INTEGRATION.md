# Generic AI client workflow

The currently supported universal path is user-controlled copy/paste: choose **Prepare prompt for AI app**, use any chat/agent available to you, then paste its JSON into Import and validate it. The plugin does not automate, scrape or transmit prompts to external AI services.

Custom MCP connectivity is planned, not yet available. MCP client support, local stdio access and subscription capabilities differ by client/version. Do not infer support from the app name alone; verify exact configuration and tool invocation in that product before documenting compatibility.
